# DevTask

Мениджър на задачи по проекти за курса **AI-Assisted Development**.

## Стартиране

Необходим е Node.js 20 или по-нова версия. Проектът няма външни зависимости.

```bash
npm run dev
```

Отвори `http://localhost:5173`. За първи преглед избери **Примерни задачи** или създай собствена задача.

```bash
npm test
npm run build
```

`dist/` съдържа готовия статичен сайт. ES modules изискват HTTP сървър; не отваряй `index.html` чрез `file://`.

## Функции

- Създаване, редактиране, завършване и изтриване с потвърждение.
- Проекти, статуси, приоритети, краен срок и описание.
- Комбинирани филтри, търсене на кирилица и подреждане.
- Изгледи за всички задачи, за днес и за завършените.
- Брой задачи и процент завършени; адаптивен интерфейс.
- Версиониран запис в localStorage и изтегляне на JSON копие.
- Защита срещу презаписване на повредени данни; възстановяване чрез изрично изчистване.
- Обновяване при промени в друг раздел на същия браузър.

## Архитектура

| Модул | Файлове | Отговорност |
| --- | --- | --- |
| Логика | `src/model.js` | Валидация, операции, филтри, статистика |
| Съхранение | `src/storage.js` | JSON схема, localStorage, обработка на грешки |
| Интерфейс | `index.html`, `src/ui.js`, `src/main.js`, `src/styles.css` | DOM, събития, диалози, адаптивен дизайн |
| Проверки | `tests/`, `docs/evidence/` | Автоматизирани тестове и реални снимки |

Поток: събитие от интерфейса → валидация и ново състояние → успешен запис → обновяване на екрана. При неуспешен запис старото състояние се запазва.

## Обхват и ограничения

Данните са локални за конкретен браузър и origin. Няма акаунти, облачна синхронизация или сървърна база данни. Изчистването на данните на браузъра ги премахва. JSON изтеглянето е резервно копие; автоматичен импорт не е включен. При едновременни записи от различни раздели важи последният успешен запис; това не е система за съвместна работа.

Избрани са обикновени ES modules и вграденият Node.js test runner вместо Vite и Vitest, за да се стартира и проверява без инсталиране на пакети. Тази промяна запазва модулността и обхвата на първоначалния план.

## AI съдействие

Проектът е разработен с **ChatGPT/Codex**. Няма заявена употреба на Copilot, Claude Code, Augment или Cursor. Преглед на действителните взаимодействия: `docs/AI_PROCESS.md`. Използването на този инструмент вместо изрично изброените в условието следва да бъде уточнено с преподавателя.
