# Процес на разработка с AI

Проектът използва **ChatGPT/Codex** за първата версия и изпълнението на проверките и **GitHub Copilot Chat** за независим преглед, целеви корекции и допълнителни тестове.

## Архитектура и първа версия

Системата е разделена на логика, съхранение, интерфейс и проверки. Чистите функции са отделени от DOM и localStorage. Използвани са ES modules и вграденият Node.js test runner, без външни зависимости. Първият браузърен преглед откри липсващ crypto.randomUUID в HTTP среда; добавен е UUID v4 fallback с getRandomValues и регресионен тест.

## Реална работа с GitHub Copilot

На 2 ноември 2026 г. е отворен Copilot Chat в GitHub с прикрепено хранилище Nahapsumm/DevTask-SoftUni. Използван е наличният Copilot Free и режим Model Auto. Изпратени са две действителни заявки с отделни инструкции за четирите модула.

1. Преглед на реалните файлове: подход, граничен случай и проверка за всеки модул.
2. Конкретни code snippets/diff и тестове за установените случаи, без нови зависимости.

Пълният текст на заявките и отговорите е в `docs/evidence/copilot-review.md`.

## Приети решения

- Логика: контролирана грешка при липсващ crypto provider или UUID методи. Запазен е съществуващият UUID v4 fallback.
- Съхранение: работещият код е запазен; добавен е тест, че невалидни top-level JSON стойности не се презаписват.
- Интерфейс: явен span за заглавието заменя зависимостта от firstChild. CSS селекторът е адаптиран към текущия файл и ограничава badge стила до брояча.
- Проверки: добавени са два регресионни теста; npm test използва изрично посочени тестови файлове без shell glob.

Предложените промени са прегледани преди прилагане. Уточнено е, че подаване на undefined към функция с default параметър не симулира липсващ provider; тестовете използват null и {}. Copilot не е изпълнявал тестовете. Те са изпълнени отделно: **33 успешни, 0 неуспешни**. В Chrome са проверени актуализираните заглавия и броячи. Записът е в `docs/evidence/automated-tests.txt`.

## Ограничения

Няма автоматизирани браузърни end-to-end тестове; UI потокът е проверен в браузър. Данните са локални, а едновременна работа между устройства не е реализирана. Снимките на работещата система са приложени в курсовия документ.
